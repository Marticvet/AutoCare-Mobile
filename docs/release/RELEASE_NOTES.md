# AutoCare Mobile 1.0.0

Welcome to AutoCare Mobile.

- Keep vehicles, fuel/charging, service, insurance, and other expenses organized.
- Track reminders, documents, trips, budgets, reports, and inspections.
- Work offline and sync when a connection is available.
- Use optional nearby-service search and on-device reminder notifications.
- Available in English, German, Bulgarian, Spanish, and French.

Subscription availability, prices, and terms will be shown in the app for the selected store and region.
